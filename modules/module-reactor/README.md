# Reactor core module

![](https://img.shields.io/npm/v/@journeyapps/reactor-mod)

The core Reactor module that provides the core functionality of the application. This includes the System, Kernel and core stores
which provide functionality such as the command palette, action system, entity definitions, workspaces, forms, themes, and other application subsystems.

Start with the [Getting Started documentation](https://journeyapps.github.io/reactor/getting-started/introduction), then use the generated API reference for individual types.
